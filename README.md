# Flores amarillas 🌻

Página web hecha con Vite, GSAP y CSS responsive. Un jardín de flores
amarillas que crecen en vivo (tallo, hojas y pétalos animados), con
recuerdos, una galería de fotos con lightbox, y una cartita para Yanes.

## Ejecutar localmente

```bash
npm install
npm run dev
```

## Publicar en Render

1. Sube este repositorio a GitHub.
2. En Render crea un **Static Site** y conecta el repositorio.
3. Usa `npm install && npm run build` como build command.
4. Usa `dist` como publish directory.

Vercel también funciona muy bien para este proyecto: importa el repositorio,
dejá `npm run build` como comando de build y `dist` como carpeta de salida.
